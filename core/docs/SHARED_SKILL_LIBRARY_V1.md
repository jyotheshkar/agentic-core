## Access contract

`MOA -> capability requirements -> Skill Broker -> Skill Registry -> minimum sufficient shared skills -> selected agent execution -> verification -> Minister final review`

Recommended-agent metadata is advisory. Availability, trust, status, dependencies, and task relevance determine selection. Full skill instructions load only after broker selection.

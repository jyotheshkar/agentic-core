# First Principles

Use first-principles reasoning to improve the formulation of a problem, not to perform contrarianism.

## Method

1. State the real objective in outcome terms.
2. Extract assumptions, constraints, conventions, dependencies, and proposed methods.
3. Classify each as fundamental fact, empirical constraint, chosen requirement, convention, estimate, or unsupported assumption.
4. Test which constraints are genuinely binding and which are artificial or inherited.
5. Decompose the objective into necessary functions or truths.
6. Generate alternative formulations from those fundamentals.
7. Reconstruct the simplest option that satisfies real constraints.
8. Compare the reconstruction with the original approach, including tradeoffs and evidence needed.

Return the objective, binding truths, challenged assumptions, reframed problem, reconstructed approach, and unresolved tests. Preserve safety, legal, physical, financial, user, and compatibility constraints unless evidence supports changing them.

Read [reasoning method](references/reasoning-method.md) when the problem has several assumption layers or competing formulations.

Do not assume every convention is wrong, ignore implementation reality, or replace domain evidence with abstract logic.

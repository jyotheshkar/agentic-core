# Strategic Foresight

Foresight explores plausible futures. It does not predict one future with false certainty.

## Workflow

1. Define the focal decision, current baseline, actors, boundary, and relevant time horizons.
2. Identify drivers that are relatively stable, uncertain, externally controlled, or capable of nonlinear change.
3. Trace immediate, short-term, medium-term, and long-term consequences. Include second-order effects and third-order effects only when they are material and causally plausible.
4. Examine path dependency, lock-in, switching cost, lost options, newly created options, and compounding effects.
5. Build a small set of distinct scenarios: BASE, BEST, WORST, and SURPRISE when each changes the decision. Do not vary every factor at once.
6. Test the strategy across scenarios. Prefer robust moves, reversible probes, hedges, and signposts over a plan optimized for one forecast.
7. Identify timing conditions: act now, wait for a signal, stage the commitment, or abandon if a trigger occurs.

Return horizons, drivers, scenario implications, robust actions, fragile assumptions, signposts, and timing recommendation. State confidence and scenario limits.

Read [scenario and horizon method](references/scenario-and-horizon-method.md) for long-horizon, high-uncertainty, or path-dependent decisions.

Do not treat a scenario as a forecast, multiply speculative chains, or use distant possibilities to overwhelm near-term evidence.

# Source Discovery

## Workflow

1. Start from entities, concepts, aliases, identifiers, and date or jurisdiction constraints.
2. Search primary-source venues and metadata indexes before broad summaries.
3. Use backward and forward citation chaining where provenance matters.
4. Deduplicate by durable identifier, then record discovery query and access date.

## Output contract

A deduplicated candidate-source set with identifiers, provenance, and discovery rationale.

State evidence, assumptions, uncertainty, and missing capability separately when they affect the result. Stop or defer when a decision-reversing unknown cannot be resolved safely.

## Boundary

Discovery finds candidates. It does not establish that a source is accurate, current, or sufficient.

This skill is advisory expertise. MOA owns orchestration, Minister owns strategic judgment, Forge owns engineering implementation, and verification owns completion evidence.

## Evidence basis

Use the relevant parts of the [primary guidance](https://www.crossref.org/documentation/retrieve-metadata/rest-api/) when standards or formal evidence are material. Verify currency before making a time-sensitive claim.

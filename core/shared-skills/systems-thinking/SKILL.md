# Systems Thinking

Model only enough of the system to improve the decision.

## Workflow

1. Define the focal outcome, boundary, time horizon, and what remains outside the model.
2. Identify actors, components, stocks, flows, rules, incentives, resources, and information paths.
3. Map dependencies, constraints, bottlenecks, single points of failure, and delays.
4. Identify reinforcing loops, balancing loops, and conditions that change loop strength.
5. Compare local optimization with the global outcome.
6. Trace first-order and plausible second-order effects, including adaptations and unintended consequences.
7. Find leverage points and assess effort, delay, reversibility, and risk.
8. Recommend the smallest intervention with feedback and monitoring.

Return the boundary, critical components, dependency chain, feedback and delays, leverage points, likely unintended effects, and monitoring signals.

Read [systems analysis method](references/systems-analysis-method.md) for multi-loop systems, long delays, or competing local objectives.

Avoid decorative diagrams, exhaustive inventories, and complexity that does not change the decision. State model limitations and uncertain relationships.

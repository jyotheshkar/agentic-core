# Source Evaluation

Prefer evidence close to the underlying event or data: official records, primary documentation, original research, direct measurements, and first-hand artifacts. Secondary synthesis can clarify context but should not replace available primary evidence for decisive claims.

Check:

- identity and authority of the publisher;
- publication date versus event or data date;
- method, sample, definitions, and exclusions;
- independence and shared upstream sources;
- incentives, conflicts, selective reporting, and motivated reasoning;
- whether the source supports the exact claim rather than an adjacent one;
- falsifiability and plausible disconfirming evidence.

For contradictions, first test whether sources use different definitions, periods, populations, or confidence thresholds. If conflict remains, preserve it and reduce confidence rather than averaging incompatible claims.

# Broker Output Contract

```json
{
  "task": "Build a secure authenticated React dashboard",
  "required_capabilities": ["frontend-react", "authentication", "web-security", "browser-testing"],
  "selected": [{"id": "react-best-practices", "reason": "exact capability and authoritative source"}],
  "rejected": [{"id": "generic-frontend", "reason": "redundant with narrower candidate"}],
  "missing_capabilities": []
}
```

Use stable registry IDs. A missing capability is a normal result, not a reason to fabricate a candidate. Keep ordinary user responses concise unless the selection itself is decision-relevant.

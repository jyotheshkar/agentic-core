# Comparative Decision Method

## Model selection

- Use dominance analysis when one option is no worse on every material criterion and better on at least one.
- Use a consequence table when inputs are mainly qualitative.
- Use expected value when probabilities and outcome magnitudes have defensible ranges.
- Use a weighted matrix when criteria are distinct, weights reflect the actual objective, and totals are accompanied by sensitivity analysis.
- Use a real-options framing when waiting or staging buys information without losing the opportunity.

## Range-based expected value

Use low, central, and high cases. Explain the basis of each range. Do not imply that a calculated output is more certain than its inputs. Include downside concentration and recoverability, not only the average.

## Sensitivity

Vary the most uncertain and influential input first. Report the threshold where the leading option changes. If a plausible range crosses that threshold, call the ranking fragile.

## Opportunity cost

Include money, time, attention, flexibility, foregone learning, alternative opportunities, and future constraints. Exclude past cost unless it changes future consequences.

## Decision lock

If one unknown can plausibly reverse a hard-to-reverse decision, recommend DEFER until the minimum evidence is obtained. Name the exact evidence and a deadline or collection method.

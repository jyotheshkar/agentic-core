# Decision Science

Build the smallest model that can change the choice. Do not manufacture numerical precision.

## Workflow

1. State the decision, objective, decision deadline, time horizon, and success criteria.
2. Expand the option set beyond the presented choices: wait, do nothing, staged trial, hybrid, and a credible unlisted alternative when relevant.
3. Separate inputs into KNOWN, ESTIMATED, and UNKNOWN. Record source or basis for every decision-critical estimate.
4. Compare options on material criteria such as upside, downside, likelihood, direct and opportunity cost, time, reversibility, regret, option value, switching cost, and dependency on external actors.
5. Use expected value or a weighted matrix only when inputs support it. Show ranges or qualitative bands when point estimates would be false precision.
6. Run sensitivity and threshold analysis: identify which assumption can reverse the ranking and the value at which it does.
7. Treat sunk cost as irrelevant unless it changes future cash flow, capability, obligations, or option value.
8. Distinguish a two-way door from a one-way door. Favor learning through bounded action for reversible decisions and stronger evidence for hard-to-reverse commitments.

Return the options, evidence ledger, comparison, dominant tradeoffs, sensitivity result, and decision-relevant unknowns. This skill recommends a ranking but does not claim authority reserved by the calling agent.

Read [comparative decision method](references/comparative-decision-method.md) when quantitative estimates, several criteria, or a close ranking require a deeper model.

Do not score decorative criteria, add probabilities without a defensible basis, hide uncertainty inside a weighted total, or analyze only the user's preferred option.

# Audit

Audit is Agentic Core's fifth visible standalone agent. It independently assures supplied artifacts, evidence, policy conformance, release readiness, residual risks, and completion claims.

It must not conduct primary web research in place of Scout, implement or repair software in place of Forge, make strategic trade-off judgments in place of Minister, or orchestrate the system in place of MOA.

Run `python -B scripts/test_audit.py` for the deterministic assurance suite and `python -B scripts/audit_core.py health` for installed-registry health.

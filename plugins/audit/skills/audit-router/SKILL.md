# Audit Router

Classify the request as artifact assurance, evidence and policy review, release or completion gate, or adversarial assurance. Always select `audit-evidence-policy`. Add `audit-release-gate` only for release, publish, deployment, or completion claims. Add `audit-adversarial-assurance` only for contested claims, risk, challenge, or adversarial review.

Reject requests for primary research, implementation, strategic verdicts, or system orchestration. Return the selected private skills, prohibited authority reminder, bounded artifact set, and missing evidence. Do not inspect unrelated data.

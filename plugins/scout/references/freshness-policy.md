# Freshness Policy

Live verification is mandatory when a material fact can change, including vacancies, sponsorship, salary, immigration rules, deadlines, fees, funding, company leadership, product features, software versions, APIs, laws, regulations, schedules, prices, availability, and security guidance.

For each time-sensitive claim record:

- publication or last-updated date when available
- access date
- version, jurisdiction, or effective date where relevant
- whether the page appears current
- any staleness signal or archived status

Accessibility does not prove currency. An undated page needs corroboration or an explicit `UNVERIFIED` freshness status when currency is decision-critical. An old source can provide historical context but cannot establish a current claim without current confirmation.

For technical research, check current official documentation and relevant release notes. For policy, legal, and immigration research, check the current official text and effective dates. When current evidence cannot be obtained, keep the unknown visible and prevent unqualified completion.

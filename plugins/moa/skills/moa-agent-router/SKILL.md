# MOA Agent Router

Run `python ../../scripts/moa_core.py route "<task>"` for a deterministic baseline, then correct it only when task or repository evidence warrants.

Minister is mandatory for every substantive MOA task. Select LIGHT for tiny reversible work, STANDARD for normal bounded projects, DEEP for consequential or multi-lens judgment, and CRITICAL for difficult-to-reverse life, immigration, legal, major financial, or strategic decisions. DEEP maps to the current Minister COUNCIL mode at the handoff boundary.

Add Scout for research, discovery, source verification, claim verification, contradiction analysis, or current-evidence work. Add Forge only for genuine implementation, repair, technical audit, engineering design, or launch execution. Pure research does not select Forge. Research before a build sequences Scout before Forge. Prefer a dedicated enabled agent with exact capability coverage over a generic fallback. Disabled and unavailable agents are excluded.

Return task type, Minister level, selected agents with reasons, selected shared skills, exclusions, missing capabilities, and conditions that downstream agents must preserve.

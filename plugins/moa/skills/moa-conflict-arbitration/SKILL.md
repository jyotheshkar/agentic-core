# MOA Conflict Arbitration

Classify the disagreement, then apply authority:

- strategy and what should be done: Minister
- engineering implementation: Forge Integrator
- factual or evidence dispute: evidence-epistemics plus stronger source verification
- scope, sequencing, or orchestration: MOA
- user preference within safe permitted options: user

Minister objections are never silently discarded. REWORK returns work to the responsible node. DEFER identifies the missing decision-reversing evidence. REJECT stops the rejected strategy unless the user explicitly requires it and the action remains safe and permitted. Preserve the objection and resolution in the handoff.

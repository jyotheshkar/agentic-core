# Forge

Forge is a personal Codex plugin for taking a project prompt to the most complete working result the current environment permits. It is free-first, routes only relevant skills, challenges weak architecture, implements directly, and requires evidence before claiming success.

## Use

```text
@Forge Build a production-quality personal portfolio for an AI engineer.
```

Inspect the capability registry with:

```text
@Forge skills
```

Inspect one task's normally hidden route with:

```text
@Forge explain routing: Build a secure local-first web app.
```

Forge never spends money or performs consequential irreversible actions without explicit approval. If credentials or payment genuinely block one requirement, Forge completes all unblocked work and reports the exact remaining decision.

## Components

Forge contains seven private skills: orchestration, routing, product contract, architecture, adversarial review, integration, and verification. Reusable user-level expertise remains in the AI OS shared skill root and is selected through Skill Broker. External capabilities remain in their original installed plugins. Forge never vendors either class.

Run local validation from this folder:

```powershell
python scripts/test_forge.py
```

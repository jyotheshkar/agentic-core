# @Devil

@Devil is a rigorous devil's advocate and decision stress-testing plugin for Codex. It tests plans, decisions, assumptions, purchases, career moves, financial choices, projects, business concepts, study choices, and major life decisions before commitment.

Invoke it in a new task with `@Devil` followed by the proposal. Named modes include `attack this`, `defend this`, `decide`, `pre-mortem`, `bias check`, `alternatives`, `reality check`, `worst case`, and `make it stronger`.

The plugin uses Codex's normal research capabilities when current facts matter. It does not require an external account, MCP server, or API key.
